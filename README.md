# Client Management System
A React application for managing clients. Users can view and search client records, while admins can add, edit and delete them. I designed the interface in Figma and built it using React, CSS and Bootstrap.

## Features
- Login and registration demo
- Dashboard with client statistics
- Client list with search and pagination
- View client details
- Add, edit and delete clients as an admin
- Responsive layout for desktop and mobile

## Technologies
- React
- React Router
- JavaScript
- HTML, CSS and Bootstrap
- Fetch API
- MockAPI

## Run locally
Download or clone this repository.
With Node.js and npm installed, open the project folder in a terminal and run:
```bash
npm install
npm start
```
Open http://localhost:3000 in your browser.
An internet connection is required to access MockAPI.

## Note
This is a learning project. Login and user roles are simulated using MockAPI and localStorage, not secure authentication.
Use demo data and passwords only.
